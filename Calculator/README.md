# JavaScript Calculator

A beginner-friendly calculator built using HTML, CSS, and JavaScript. This project demonstrates how JavaScript handles user input, performs arithmetic operations, and manages application state.

## Features

- Perform addition, subtraction, multiplication, and division.
- Enter numbers through interactive buttons.
- Clear the calculator using the AC (All Clear) button.
- Handle division by zero with a friendly error message.
- Update the display dynamically based on user interactions.

## Technologies

- **HTML** — Structure of the calculator.
- **CSS** — Styling and layout.
- **JavaScript** — Arithmetic operations, event handling, input conversion, and calculation state.

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Click the calculator buttons to perform calculations.

## Concepts Learned

- Variables using `let` and `const`.
- Data types: strings and numbers.
- Type conversion using `Number()`.
- Arithmetic and comparison operators.
- Conditional statements using `if`.
- Functions and event handling.
- DOM manipulation using `textContent`.
- Managing state with variables such as `firstNumber`, `operator`, and `waitingForSecondNumber`.
- Resetting application state and handling division by zero.
