
# Interactive Webpage

A beginner JavaScript project demonstrating DOM manipulation,
event handling, and dynamic webpage updates.

## Features

- Change a message using a button
- Interactive click counter
- Reset counter
- CSS styling and hover effects

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

1. Open `index.html` in a browser.
2. Or use the Live Server extension in VS Code.
3. Click the buttons to test the interactions.

## Concepts Learned

- Variables and reassignment
- Functions and callbacks
- DOM selection and text updates
- Click events with addEventListener()
- CSS selectors and styling
